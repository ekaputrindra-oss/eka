## Praktik Administrasi dan Ping Sweep Kali Linux 🐉

## 📌 Deskripsi
Repository ini berisi dokumentasi praktik pembelajaran Administrasi Kali Linux dan Ping Sweep Kali Linux. Dokumentasi disusun dalam bentuk laporan langkah-langkah praktik yang dilakukan menggunakan sistem operasi Kali Linux.

## 📚 Materi Praktik

### 1. Ping Sweep Kali Linux
Ping Sweep merupakan praktik untuk memeriksa konektivitas jaringan dan mengetahui apakah alamat IP tertentu dapat dijangkau.

Kegiatan praktik meliputi:
- Menjalankan Kali Linux.
- Membuka terminal untuk melakukan konfigurasi.
- Menggunakan editor teks Nano.
- Mencari alamat IP.
- Melakukan pengujian konektivitas menggunakan perintah ping.

### 2. Administrasi Kali Linux
Materi ini berisi praktik dasar administrasi menggunakan Kali Linux.

Kegiatan praktik meliputi:
- Menjalankan sistem operasi Kali Linux.
- Membuka terminal.
- Menggunakan editor teks Nano.
- Membuat dan mengedit teks melalui terminal.

## 🛠️ Tools yang Digunakan
- **Kali Linux** — Sistem operasi berbasis Linux.
- **Terminal** — Untuk menjalankan perintah.
- **Nano** — Editor teks berbasis terminal.
- **Ping** — Untuk menguji konektivitas jaringan.

## 🎯 Tujuan
- Memahami penggunaan dasar Kali Linux.
- Mengenal penggunaan terminal dan editor Nano.
- Memahami pengujian konektivitas jaringan.
- Melatih keterampilan administrasi sistem Linux.
